# DRAFT 1 — Web Financial Statement Analysis (FSA)

Tanggal: 3 Nov 2026. Status: diskusi desain, belum build.

## Tujuan (diperluas atas koreksi Septian)
1. Bisa **baca laporan keuangan secara profesional** (bukan sekadar lulus quiz).
2. Output **credit memo** → portofolio lamaran kerja (credit risk).
3. Bekal **investasi saham** kelak → perlu lensa ekuitas juga, bukan cuma lensa kredit.

## Scope kurikulum
- Basis: kurikulum CFA resmi, nama topik resmi = **"Financial Statement Analysis"** (FSA). "FRA" hanya singkatan informal.
- Level 1: 13 readings (intro → mekanisme & standar → bedah 3 laporan → teknik analisis/rasio → inventories, long-lived assets, pajak, liabilitas jangka panjang → kualitas pelaporan → aplikasi).
- Level 2: 5 readings (intercorporate investments, employee compensation, multinational operations, analisis institusi keuangan, evaluasi kualitas laporan — lebih dalam).
- Level 3: TIDAK ada FSA standalone → aplikasinya dilipat ke case L2. Tidak mengarang "L3 FSA".

## Format pembelajaran (Draft 1 — disetujui Septian 3 Nov)
1. **Case-first / investigasi**: tiap topik dibuka laporan keuangan asli emiten IDX + satu pertanyaan tajam; teori = alat menjawab.
2. **Forensik skandal per topik**: tiap standar dipelajari lewat cara orang mengakali standar itu (contoh: Garuda–Mahata Air 2018 untuk revenue recognition; Enron untuk off-balance-sheet).
3. **Toggle IFRS vs US GAAP**: transaksi sama, lihat beda perlakuannya (LIFO, reversal impairment, dsb.) — favorit soal CFA.
4. **Dual lens per case**: tiap case dianalisis dari **lensa kredit** (bisa bayar? downside?) DAN **lensa ekuitas** (layak dibeli? kualitas laba? valuasi?) → output 2 one-pager: credit memo + equity note.
5. **Sudut PSAK** di tiap lesson: nomor PSAK, berlaku sejak kapan di Indonesia, kasus lokal.
