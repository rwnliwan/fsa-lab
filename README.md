# FSA Lab — Three-Lens Ledger

**Baca lebih dari sekadar angka. / Read beyond the numbers.**

Kursus analisis laporan keuangan (Financial Statement Analysis) berbasis case-first dan forensik, dengan tiga lensa: investasi, kredit, dan forensik. 38 modul, toggle IFRS vs US GAAP, hard gate 80%.

**Live:** https://fsa-lab.pages.dev/

## Isi

- **38 modul** (M1–M38) — dari mekanik laporan keuangan sampai laporan interim/kuartalan
- **Bedah Sendiri** — KLBF, BBRI, MIKA (latihan dengan filing asli IDX)
- **Ujian buta** — BBCA interim H1 2026 + ujian transfer UNVR 2024
- **Builders** — Research Note, Red-Flag Memo, Memo Kredit
- **Tools/Lab** — Ratio Lab, Komparator, Simulator, Spot-Fraud, dan lainnya

## Teknologi

Static site — HTML/CSS/JS murni, deploy via Cloudflare Pages. Jurnal progres tersimpan di localStorage (tanpa backend).
